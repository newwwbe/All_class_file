변형 문제 정답 · 해설 (4~7장)

문제는 코딩시험_변형문제_시각화.html, 원본 해설은 코딩시험_정답_해설.html. 각 문제는 노란 상자(원본 정답에서 고칠 곳) → 정답 코드 순서입니다. 구조는 원본과 같으니 노란 상자만 보고 원본 코드를 고쳐 보는 연습을 추천해요.

공통 (원본 해설과 같음)

  • package·import는 생략. 빨간 글자에서 Alt+Enter.
  • switch + case R.id.xxx 대신 if / else if.
  • 리스너 안 Context는 클래스명.this 또는 getApplicationContext().
  • AlertDialog는 androidx.appcompat.app.AlertDialog.

변형 12. 무작위 위치 토스트 ★★

문제 보기 →
원본 정답에서 고칠 곳
· XML: 바깥 gravity="center" → "bottom|center_horizontal", 버튼 글자
