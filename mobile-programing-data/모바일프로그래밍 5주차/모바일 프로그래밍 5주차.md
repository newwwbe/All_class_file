## Scanner 클래스 이용

* &#x20;Scanner 클래스는 다양한 형태의 입력을 쉽게 받을 수 있도록 도와주는 도구
* 단일문자(문자형),정수,실수,문자열까지 입력가능

###### 실습#19 - 표준입력메소드3(Scanner클래스)

* Scanner 클래스를 사용하려면 Java.util.Scanner 를  import
* <순서>
1. 객체생성: Scanner scan = new Scanner(System.in); => Scanner라는 클래스로부터 표준입력용 객체인 scan을 생성하기
2. 입력메소드 사용: 필요에 따라 정수,문자열 등 다양한 메소드를 호출하여 입력값을 받는다.
* nextInt() => 정수입력. nextDouble() => 실수 입력, next() => 공백전까지의 문자열 입력(단어), nextLine() => 한 줄 전체의 문자열 입력

3\.    객체 닫기: 입력처리가 끝나면 반드시 Scanner.close를 호출하여 자원을 해제 (\*P/G을 종료하면 자동해제 )

###### 실습#21-증가, 감소 연산자

* 증가(++) => 전치(Prefix),후치(Postfix)
* 전치 ex) a = ++b; => 1. b의 값 1만큼 증가, 2. 증가된 값을 a에 대입
* 후치 ex) a = b++; => 1. b의 값을 a에 대입, 2. b의 값을 1만큼 증가
* 감소(--) => 전치, 후치

###### 실습#26- 쉬프트연산자(<<, >>)

* << : Left shift
* >> : Right shift

Ex) a =10; , b = (a<<2);  => 1. a의 값을 2진수로 변환, 2. 비트단위로 좌측으로 2칸만큼 이동, 3. 10진수로 변환된 값이 b에 저장

a = 0; 	(1) 2진수로 변환

a <<2; 	(2) 비트단위 좌측으로 2칸만큼 이동
