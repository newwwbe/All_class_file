* 자바에서 키보드로부터 값을 입력받는 방법(표준입력메소드)
* System.in.read()이용
* 키보드로부터 1byte씩 데이터를 읽어들이는 메소드
* 엔터키를 누르기 전까지는 입력이 버터에 저장되다가, 엔터키를 누르는 순간에 버퍼에 버퍼에 있는 첫 1byte를 읽어 정수형태로 변환
* 즉 문자의 아스키 코드 값을 변환
* system.in.read() 메소드 1byte씩만 읽기 때문에 문자열을 입력받는데는 부적합하다.



실습#17-자바-표준입력메소드1

* C언어에서 표준입력함수인 scanf()는 입력값을 선언한 변수에 저장한다. 예) scanf("%d", \&a);  => a라고 선언된 기억장소에 입력값을 전달.
* 자바에서 표준입력메소드인 System.in.read()는 여러 개의 문자열 또는 두자리이상의 숫자가 입력되더라도 오직 1개의 문자 또는 숫자만 받아들인다.



실습#18-자바-표준입력메소드2

* System.in.read()메소드는 1byte씩만 읽기때문에 여러글자를 입력받을 수 없다. 또한 정수를 받아들이면 48을 더해서 저장한다.
* 따라서 정확한 수를 입력받기 위해서는 다음과 같이 작성한다.  a = System.in.read() -48
