시험 범위와 체크리스트

범위는 실습 #1~#28(중간과제와 같음)이고, 13시 102호 실습시험입니다. 문제는 크게 두 종류로 나옵니다: 순수 Java 콘솔 프로그램(#5~#12, #15~#26)과 안드로이드 XML(+Java) 앱(#1~#4, #13~#14, #27~#28).

시험장에서 매번 확인할 것:

  • 첫 줄 주석: //박상훈#번호-제목
  • 입력을 받으면 import java.util.Scanner; 또는 import java.io.IOException; + throws IOException
  • 변수는 메소드 안에서 선언하고 반드시 초기화
  • float는 숫자 끝에 F, char는 ' ', String은 " "
  • 위젯이 2개 이상이면 android:orientation="vertical"
  • id는 @+id/이름 (+ 빠뜨리지 말 것), 저장(Ctrl+S) 후 Java에서 사용
  • setText()에는 문자열만: 숫자는 String.valueOf()로 변환
  • % 기호를 출력하려면 %%
이클립스 단축키: Ctrl+Space 자동완성 · Java에서 Ctrl+/ 한 줄씩 주석 · Ctrl+Shift+/ 블록 주석(XML에서는 <!-- -->). 객체명에 빨간 줄이 생기면 마우스를 올려 첫 번째 항목(import)을 선택.

XML + Java 연결 (객체변수, #13·#14·#28)

위젯 id와 Java 객체변수는 다른 파일에 있으므로 findViewById()로 연결해야 값을 넘길 수 있습니다.

  1. XML에서 위젯에 id 부여: android:id="@+id/a_txt"
  2. 저장(Ctrl+S)해서 id를 메모리(R 파일)에 올린다
  3. Java 멤버변수부(클래스 바로 아래)에 객체변수 선언: TextView a_T;
  4. onCreate() 안에서 연결: a_T = (TextView) findViewById(R.id.a_txt);
  5. 값 전달: a_T.setText("문자열");
java
package com.knu.psh14;

import android.os.Bundle;
import android.app.Activity;
import android.widget.TextView;
import android.widget.EditText;

//박상훈#14-객체변수사용법2
public class PSH14 extends Activity {
    // 멤버변수부: id를 준 위젯만 객체변수로 선언
    TextView a_T, b_T, c_T;
    EditText a_E;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.main);

        // 객체변수와 위젯 id 연결 (오류 나면 캐스트 (TextView) 붙이기)
        a_T = (TextView) findViewById(R.id.a_txt);
        b_T = (TextView) findViewById(R.id.b_txt);
        c_T = (TextView) findViewById(R.id.c_txt);
        a_E = (EditText) findViewById(R.id.a_edt);

        int e = 777;
        float f = 3.14F;
        String h;

        a_T.setText("안녕하세요.");
        // b_T.setText(e);  -> 오류! 정수는 바로 못 넣음
        h = String.valueOf(e);   // 정수 -> 문자열
        b_T.setText(h);
        h = String.valueOf(f);   // 실수 -> 문자열
        c_T.setText(h);
    }
}

일반변수(int, float, char)는 메소드 안에, 객체변수(TextView, EditText)는 멤버변수부에 선언합니다.

Java 기초: 변수와 출력 (#5~#12)

자료형저장초기화 예서식문자
int정수a = 77;%d
float실수a = 123.45f; (F 필수)%f
double더 큰/정밀한 실수b = 123.45;%f, %7.2f
char문자 1개d = 'M';%c
String문자열e = "안녕";%s
boolean참/거짓c = (a >= b);%b

%f 기본은 소수점 6자리, %7.2f = 전체 7칸(점 포함), 소수점 아래 2칸.

메소드동작
System.out.print()출력만, 줄바꿈 없음
System.out.println()출력 후 줄바꿈 (println()만 쓰면 빈 줄)
System.out.printf()서식문자에 맞춰 출력, 줄바꿈은 \n

+ 연산자: 숫자+숫자는 덧셈, 문자열+숫자/문자열은 이어붙이기. String.valueOf(숫자)는 숫자를 문자열로 바꿉니다.

java
//박상훈#12-일반변수와 출력메소드 종합연습
public class PSH12 {
    public static void main(String[] args) {
        int a;  float b;  double c;  char d;  String e;
        a = 100;
        b = 3.14F;
        c = 3.14159;
        d = 'M';
        e = "박상훈님 반갑습니다.";

        System.out.print(a);        // 100 (줄바꿈 없음)
        System.out.println(a);      // 100 + 줄바꿈 -> "100100"
        System.out.printf("정수형변수a=%d\n", a);
        System.out.printf("실수b=%f, c=%7.2f\n", b, c);
        System.out.printf("문자=%c, 문자열=%s\n", d, e);

        e = String.valueOf(a);      // "100"
        System.out.printf("변수=%d\n", a + 100);        // 200 (덧셈)
        System.out.printf("붙이기=%s\n", e + 777);      // 100777 (연결)
    }
}

키보드 입력 (#17~#20)

System.in.read() — 1바이트(문자 1개)만 읽고 아스키코드로 돌려줍니다. 숫자로 쓰려면 48을 뺍니다('0'=48 … '9'=57). import java.io.IOException;과 throws IOException이 필요합니다.

합계·평균(#16) 응용: s = a + b; c = s / 2.0F; — 정수끼리 나누면 소수점이 버려지므로 2.0F로 나눕니다.

연산자 (#15, #21~#26)

종류연산자예 → 결과 (a=7, b=3)실습
산술+ - * / %a/b → 2 (정수끼리는 몫), a%b → 1#15
증가·감소++ --c = a++ → c=7, a=8 / d = ++b → b=4, d=4#21
복합대입+= -= *= /=c += a → c = c + a#22
관계> >= < <= == !=a >= b → true (boolean, %b)#23
논리&& || !둘 다 참일 때만 참 / 하나라도 참 / 반대#24, #25
시프트<< >>10 << 2 → 40, 10 >> 2 → 2#26

후치(a++)는 대입 먼저, 증가 나중, 전치(++a)는 증가 먼저, 대입 나중. 시프트는 2진수로 바꿔 비트를 옮기는 것으로, << n은 ×2ⁿ, >> n은 ÷2ⁿ(몫)과 같습니다.

java
import java.util.Scanner;

//박상훈#21-증가, 감소 연산자
public class PSH21 {
    public static void main(String[] args) {
        int a, b, c = 0, d = 0;
        Scanner kk = new Scanner(System.in);
        System.out.println("정수 1개를 입력하세요.");
        a = kk.nextInt();
        System.out.println("정수 1개를 입력하세요.");
        b = kk.nextInt();
        c = a++;    // 후치: c에 a 대입 후 a 증가
        d = ++b;    // 전치: b 증가 후 d에 대입
        System.out.printf("변수 a = %d, c = %d\n", a, c);
        System.out.printf("변수 b = %d, d = %d\n", b, d);
    }
}

자주 틀리는 점과 원본 코드의 오류

깃허브에 올라간 중간과제 코드에서 그대로 따라 치면 안 되는 부분이 몇 군데 있습니다.
위치원본고칠 것
#27 main.xmlandroid:id="@id/a_edt"@+id/a_edt — + 가 없으면 id가 새로 만들어지지 않아 오류
#26 printf 두 번째 줄"%d << 2 = > %d" (c 출력)"%d >> 2 => %d" — 오른쪽 시프트 결과임
#5, #6, #13, #14 등주석 줄이 깨져 코드가 두 번 붙어 있음파일 복사 중 생긴 흔적, 클래스는 한 번만
#28 Java@Override 빠짐onCreate 위에 @Override (없어도 동작은 함)
#20 printf"부피: %f"끝에 \n을 넣어야 줄바꿈됨

그 밖에 실수하기 쉬운 것:

  • setText(777)처럼 숫자를 바로 넣으면 오류 (정수를 리소스 id로 착각) → String.valueOf()
  • float b = 3.14; → F가 없으면 double로 인식되어 오류
  • System.in.read()를 쓰면서 throws IOException을 빼먹음
  • Scanner를 쓰면서 import java.util.Scanner;를 빼먹음
  • 관계·논리 결과를 int에 저장 → boolean으로 선언, 출력은 %b
  • char는 작은따옴표 'A', String은 큰따옴표 "A"
  • 정수끼리 나눗셈은 몫만 나옴: 7/3 = 2, 평균은 2.0F로 나누기
