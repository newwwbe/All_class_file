# 모바일프로그래밍 11/16 — 9장 레이아웃 (예제 41)

| 번호 | 내용 | 위젯 |
|---|---|---|
| 41 | 리니어레이아웃1 안에 리니어레이아웃 3개 배치 (화면 3등분) | TextView, LinearLayout 3 |

## 레이아웃이란
- **위젯들을 배치해서 화면을 구성하는 틀** (위젯 = 화면을 구성하는 요소, 윈도우의 아이콘 같은 것)
- 종류: 리니어, 렐러티브, 프레임, 테이블, 그리드
  - 렐러티브: 새 프로젝트의 기본값이지만 잘 안 씀
  - 그리드: 게임 만들 때 말고는 잘 안 씀
  - **수업에서 배우는 3가지: 리니어, 프레임, 테이블**

## 리니어 레이아웃
- 위젯을 **좌측 상단부터 위에서 아래로 차례차례** 배치 (한 줄에 하나씩, 선형)
- 지금까지(1~40번) 대부분의 실습에서 사용
- 그래서 버튼을 한 줄에 여러 개(계산기처럼) 넣을 수 없었음

## 41번 구조
```
리니어레이아웃1 (바깥 배경, fill_parent, vertical)
├─ TextView
├─ 리니어레이아웃2 (노랑)
├─ 리니어레이아웃3 (빨강)
└─ 리니어레이아웃4 (파랑)
```
- 2·3·4는 **서로 영역을 침범할 수 없는 독립적인 공간**
- 바깥 테두리(리니어레이아웃1) 없이 2·3·4만 둘 수는 없음

## 속성
- `layout_width`: 가로 폭, `layout_height`: 세로 높이
- `layout_weight`: 가중치. 1:1:1이면 3명이 3분의 1씩 나눠 가짐
- **화면을 등분하려면 `layout_height`를 `wrap_content`가 아니라 `match_parent`로, `layout_weight`는 1로**
- `background`: 배경색. 네이버에서 "색상 코드표" 검색해서 `#FFFF00` 같은 코드 복사

## 이클립스 팁
- 레이아웃 입력: `<` 다음 **Shift + L**(대문자)로 LinearLayout 자동완성
- 태그 왼쪽 **`-` 기호로 접어두기**, `+`로 펼치기 (레이아웃이 많을 때 덜 헷갈림)
- 그래픽 레이아웃으로 구조 확인 가능, 화면 호환 문제가 있을 수 있으니 에뮬레이터도 켜두기

> 색깔은 강의에서 "노란색 계통, 붉은색 계통"만 언급되어 노랑/빨강/파랑으로 임의 지정.
> 쉬는 시간 뒤 과제(42번)는 녹음에 없어 미포함.
