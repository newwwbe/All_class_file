01추론통계 vs 기계학습

둘 다 표본 데이터를 쓰지만 목표가 다릅니다. 추론통계는 표본으로 모집단을 이해하려 하고, 기계학습은 표본으로 새 데이터를 정확히 예측하려 합니다.

추론통계기계학습
목적표본으로 모집단 매개변수(평균, 표준편차) 추정·가설검정보지 못한 새 데이터를 예측·분류하는 모델 개발 (일반화)
방법신뢰구간, 가설검정훈련 세트로 학습 → 별도 테스트 세트로 성능 평가
결과불확실성을 정량화 ("95% 확신")예측값과 예측 오차 (RMSE 등)
주의점주로 범주형 독립변수 (예: 분산분석, 3개 이상 그룹 평균 비교)과대적합: 훈련 데이터의 노이즈·이상치까지 학습해 새 데이터 성능이 떨어짐
자동차 대여 예시"대여 시간과 가격은 상관관계가 있다, 대여 시간이 가격에 영향을 준다""대여 시간이 2시간이니 가격은 20,000원이다"

기계학습의 종류

  • 지도학습: 정답(Label) 있음 → 분류, 정확한 결과 예측. 회귀(회귀분석·신경망·SVR)와 분류
  • 비지도학습: Label 없음 → 데이터의 패턴·구조로 분류
  • 강화학습: 행동에 보상, 누적 보상을 최적화하는 의사결정

변수의 종류

  • 양적 변수: 연속형(키, 몸무게) · 이산형(성공횟수, 교통사고 건수)
  • 질적 변수: 순위형(학년, 선호도) · 명목형(성별, 혈액형)

회귀분석의 종속변수·독립변수는 연속형이어야 합니다. 종속변수 = 독립변수에 의해 설명·예측되는 변수, 독립변수 = 예측(설명) 변수.

02회귀모형의 구조

회귀분석은 하나의 종속변수와 하나 이상의 독립변수 사이의 함수 관계를 수학적 모형으로 가정하고, 데이터로 미지의 회귀계수를 추정해서 현상을 설명·예측하는 방법입니다. 한 줄로: 하나의 선으로 잔차가 최소인 모델.

단순회귀분석의 목적

두 변수가 관련이 있는지, 있다면 그 관계를 수학적 함수(직선)로 나타낼 수 있는지, 그 함수로 새 값을 예측할 수 있는지를 보는 것. 화석 예시로 말하면, 대퇴부와 상박부가 어떤 관계인지 기존 데이터로 학습해 함수를 만들고, 대퇴부만 남은 화석이 나오면 상박부 길이를 예측합니다.

슬라이드 6쪽의 세 질문: (1) 키와 몸무게는 관련이 있는가? (2) 관계를 수학적 함수로 나타낼 수 있는가? (3) 그 함수로 키에서 몸무게를 예측할 수 있는가?

회귀분석의 구조 그림 (슬라이드 13쪽)

설명할 때: 학습 데이터로 함수(=모델)를 만들고, 그 모델에 새로운 데이터(검증 데이터)를 넣어 결과를 낸다. 실습의 lm()이 "함수 만들기", predict(newdata=)가 "새 데이터 넣기", RMSE가 "결과 확인"에 해당합니다.

y = β₀ + β₁x + ε
β₀ 상수(절편) · β₁ 회귀계수(기울기) · x 독립변수 · y 종속변수 · ε 오차항
β̂₁ = Σ(Xᵢ − X̄)(Yᵢ − Ȳ) / Σ(Xᵢ − X̄)²
β̂₀ = Ȳ − β̂₁X̄ ← 회귀선은 항상 (X̄, Ȳ)를 지난다

β₁ (회귀계수)

x가 1단위 증가할 때 y의 평균 변화량. 양수면 x↑ → y↑, 음수면 x↑ → y↓.

β₀ (절편, 상수)

모든 독립변수가 0일 때 종속변수의 기준 수준. lm(y ~ 0 + x)로 절편을 0에 고정할 수 있습니다.

회귀분석 프로세스 (4단계)

  1. 산점도를 그린다 (독립변수 vs 종속변수)
  2. 산점도를 보고 적절한 회귀모형을 선택한다 (직선? 곡선?)
  3. 자료로 회귀계수를 추정한다 (최소제곱법)
  4. 회귀모형의 적용이 옳은지 판단한다 (p-value, R², 가정 검정)

회귀의 종류

종류설명모형
단순회귀독립변수 1개, 직선 관계y = β₀ + β₁x + ε
다중회귀독립변수 2개 이상, 1차 선형y = β₀ + β₁x₁ + … + βₖxₖ + ε
곡선회귀독립변수 1개, 2차 이상 곡선y = β₀ + β₁x + β₂x² + … + βₖxᵏ + ε
다항회귀다중회귀 + 곡선회귀β₃x₁x₂ + β₄x₁² + β₅x₂² …
비선형회귀회귀계수가 선형으로 표현되지 않음y = β₀β₁ˣ + ε

예제: 시조새 화석 (대퇴부 → 상박부)

상박부 = −3.66 + 1.197 × 대퇴부. 대퇴부가 50 cm이면 상박부 = −3.66 + 1.197×50 = 56.2 cm. 상관계수 r = 0.99.

"회귀(regression)"는 Francis Galton이 처음 사용. 키 큰 아버지의 아들은 평균보다는 크지만 아버지보다는 작은 경향 → 평균으로의 회귀.

03오차 · 잔차 · 최소제곱법

오차 (Error, ε)잔차 (Residual, e)
정의데이터가 만들어질 때 섞이는 본질적 잡음관찰값 − 모델 예측값
관찰관찰 불가능 (이론적 개념)계산 가능
출퇴근 예시예상치 못한 도로 폐쇄처럼 모델에 없는 요인예측 30분, 실제 35분 → e = +5분 / 실제 28분 → e = −2분
잔차 = 순수 오차 + 모형화 오차(모델의 미스매치)
가정: εᵢ ~ iid N(0, σ²) — 서로 독립, 평균 0, 분산 일정한 정규분포

오차항의 특징 (4가지)

  • 완전성: 모델이 모든 것을 포착하지 못한다
  • 복잡성: 데이터 제한·알 수 없는 요인 때문에 모든 변수를 넣을 수 없다
  • 유연성: 설명 못 하는 부분은 두고, 체계적 관계 포착에 집중한다
  • 통찰력: 누락된 부분을 보고 추가할 변수를 찾을 수 있다

오차항 예 (집값): 위치, 관리 상태, 시장 동향.

최소제곱법(OLS): SSE = Σ(Yᵢ − Ŷᵢ)² 를 최소로 하는 β₀, β₁ 을 찾는다

04상관분석 (Pearson)

Cov(X,Y) = Σ(Xᵢ − X̄)(Yᵢ − Ȳ) / (n − 1) ← 같이 움직이는 방향 (부호 있는 면적의 평균)
r = Cov(X,Y) / √(Var X · Var Y) = Σ(X−X̄)(Y−Ȳ) / √(Σ(X−X̄)² · Σ(Y−Ȳ)²)
공분산을 두 변수의 표준편차로 나눠 정규화 → −1 ≤ r ≤ 1

성질

  • 0 < r ≤ 1: 양의 직선적 상관 / −1 ≤ r < 0: 음의 상관
  • r = 0: 직선적 상관관계 없음
  • 독립이면 Cov = 0, 하지만 Cov = 0이라고 반드시 독립은 아님
  • 극단값(이상치)에 영향을 많이 받음
  • Pearson = 선형 관계, Spearman 순위 상관 = 비선형 관계

가설

  • H₀: ρ = 0 (상관관계 없음)
  • H₁: ρ ≠ 0 (양측) 또는 ρ > 0, ρ < 0 (단측)
library(psych)
r <- corr.test(heights, weights, method="pearson")
r$p  # p-value
r$r  # 상관계수

05R² (결정계수)와 평가지표

SST = Σ(yᵢ − ȳ)² 총 변동
SSE = Σ(yᵢ − ŷᵢ)² 잔차 제곱합 (설명 못 한 변동)
SSR = Σ(ŷᵢ − ȳ)² 회귀로 설명된 변동 · SST = SSR + SSE
R² = SSR / SST = 1 − SSE / SST 단순회귀에서는 R² = r²
Adjusted R² = 1 − [SSE / (n − k − 1)] / [SST / (n − 1)] n 표본수, k 독립변수 수

R² 해석

  • 독립변수가 종속변수를 얼마나 잘 설명하는가 = 설명력. "평균으로 찍는 것보다 얼마나 나은가"
  • 0 근처: 거의 설명 못 함 · 0.3~0.5: 사회과학에서 쓸 만함 · 0.7↑: 강함 · 0.9↑: 매우 강함
  • 독립변수를 추가하면 무조건 올라감 → 그래서 Adjusted R²(자유도 반영) 사용
  • 절편 없는 모델이나 잘못된 예측에서는 음수도 가능
  • 비율이라 절대 오차 크기는 모름 → RMSE 등이 필요

R² vs RMSE

  • R² = 설명력: 종속변수 분산 중 독립변수가 설명한 비율
  • RMSE = 예측력(모형의 안정성): 예측값과 실제값의 차이 크기, y와 같은 단위
지표공식잔차 처리이상치에 강한가특징
MAEΣ|y − ŷ| / n절대값Yes과대/과소 방향 모름
MSEΣ(y − ŷ)² / n제곱No특이값에 민감
RMSE√(Σ(y − ŷ)² / n)제곱No실제값과 같은 단위로 해석 쉬움
MAPEΣ|(y − ŷ)/y| / n × 100%절대값Yes얼마나 틀렸나 (%)
MPEΣ(y − ŷ)/y / n × 100%—Yes어느 쪽으로 틀렸나 (부호 유지)

  3. 모델 전체 p-value: F = 5237, H₀ "독립변수는 종속변수를 유의미하게 설명하지 않는다" → p < 2.2e-16 < 0.05 기각, 모델이 유의하다.
  4. 설명력 R²: 0.8399 → 상박부 변동의 약 84%를 대퇴부로 설명. 0.7 이상이라 설명력이 강하다.
  5. 판단: 회귀식 상박부 = 5.784 + 0.389 × 대퇴부. 계수와 모델 모두 유의하고 설명력도 높으므로 괜찮은 모델이다.

반대 사례도 알아 두세요. 당뇨 데이터 다중회귀는 모델 p-value가 1.5e-09로 유의하지만 R²가 0.056(설명력 5.6%)밖에 안 됩니다. "유의하지만 설명력은 매우 낮다"고 둘 다 적어야 합니다. → 실전 리허설

판단 기준은 p-value 0.05 (5%)입니다. 메모에 "0.05%"라고 적힌 부분은 0.05의 오기입니다.

07다중회귀와 분석 절차

왜 다중회귀를 하나? 종속변수에 영향을 주는 요인은 보통 여러 개입니다. 예금 유치액을 홍보비용 하나로만 설명하는 것보다 직원 수, 지점 크기까지 넣으면 더 정확한 정보를 얻습니다. 독립변수가 2개면 회귀선 대신 회귀평면(초평면)을 추정합니다.

단순: ŷ = 10 + 2.0·홍보비용
다중: ŷ = 9.23 + 1.95·홍보비용 + 0.15·직원수 (예금 유치액, 지점 10곳)
각 계수 = 다른 변수를 고정했을 때 그 변수 1단위 증가에 따른 y의 변화

교수님이 말씀하신 순서 그대로 (당뇨 데이터, 종속변수 Diabetes)

"그대로 진행해 주시면 됩니다." 아래 순서를 지키는 게 핵심입니다. 문제에서 요구하면 표시된 단계는 문제에 "~를 도출하시오", "~를 빼시오"가 있을 때만 하면 됩니다.

p > 0.05가 "좋은" 이유

가정 검정은 H₀가 "가정을 만족한다"(예: 잔차가 정규분포를 따른다)입니다. 그래서 p > 0.05 → H₀ 채택 → 가정 만족. 회귀계수 검정(p < 0.05가 좋음)과 방향이 반대라 자주 헷갈립니다.

Durbin-Watson 통계량

  • 범위 0 ~ 4
  • 0 근처: 양의 자기상관
  • 2 근처 (1.5~2.5): 독립
  • 4 근처: 음의 자기상관

정규성 검정 선택

  • Shapiro-Wilk: 표본 2,000 미만
  • Kolmogorov-Smirnov: 표본 2,000 초과
  • Q-Q plot: 시각적 판단 (Z-score = 잔차/표준편차)

09이상치 검정과 다중공선성

influencePlot 읽기

  • X축 Hat (레버리지): 독립변수 값이 평균에서 얼마나 떨어진 특이한 위치인가
  • Y축 StudRes (스튜던트화 잔차): 그 점을 뺀 나머지로 추정한 표준편차로 나눈 잔차 = 얼마나 틀렸나
  • 원 크기 Cook's D: 모델에 주는 영향력
Cook's D < 0.5 → 영향점 없음
0.5 ~ 1 → 확인 필요
> 1 → 영향점

다중공선성 (VIF)

두 개 이상의 독립변수가 서로 높은 상관 → 회귀계수가 매우 커지고, 변동성이 커져 계수 부호가 실제와 반대가 될 수도 있음. 고차항과 원변수도 수학적으로 강한 상관.

VIF = 1 / (1 − R²ⱼ)
R²ⱼ: j번째 변수를 나머지 독립변수로 회귀한 R²
VIF ≥ 10 → 다중공선성 있음

제거 후에도 R²가 유지되거나 높아지는 모델을 찾습니다. Auto 데이터에서는 cylinders, displacement, horsepower, acceleration을 빼고 재분석.

10AIC를 이용한 변수선택

AIC = −2 × log-likelihood + 2 × k k = 추정한 파라미터 수
  • 모형 적합도(로그우도)와 복잡도(변수 수)를 동시에 고려
  • 절대 기준이 없음 → 작을수록 좋은 모델이라는 상대 비교만 가능
  • 변수를 빼거나 넣었을 때 AIC가 줄어들면 그 선택이 의미 있음
방법시작 모형R

E1단순회귀분석은 어떤 목적으로 수행하나요?서술

독립변수 하나와 종속변수 사이에 관계가 있는지 보고, 있다면 그 관계를 y = β₀ + β₁x 같은 직선 함수로 나타내서, 새로운 x가 들어왔을 때 y를 예측하려고 한다. 예를 들어 대퇴부 길이로 상박부 길이를 예측하는 것처럼, 기존 데이터로 함수를 학습하고 새 데이터에 적용한다.

핵심 단어: 관계 파악 · 함수(식)로 표현 · 예측

E2회귀식 y = β₀ + β₁x + ε 을 설명하세요.서술

y는 예측하려는 종속변수, x는 영향을 주는 독립변수. β₀는 x가 0일 때의 기준값(절편), β₁은 x가 1 늘 때 y가 평균적으로 얼마나 변하는지(기울기)를 나타내고, 양수면 같이 늘고 음수면 반대로 움직인다. ε은 모델로 설명하지 못하는 오차. β₀, β₁은 잔차 제곱합(SSE)이 가장 작아지도록 최소제곱법으로 구한다.

핵심 단어: 종속/독립 · 절편 · 기울기 = 1단위 변화량 · 오차 · 최소제곱법

E3회귀분석의 구조를 그림과 함께 설명하세요.서술

[학습 데이터] → [함수 = 모델, y = ax + b] → [결과]. 학습 데이터로 함수를 만들고, 새로운 데이터(검증 데이터)를 그 모델에 넣어 결과를 예측한다. 모델이 잘 맞는지는 검증 데이터의 실제값과 예측값을 비교(RMSE 등)해서 확인한다.

그림에 들어갈 것: 학습 데이터 · 함수=모델 · 결과 · 새로운 데이터(검증)

E4오차항에 대해 설명하세요.서술

오차는 데이터가 만들어질 때 섞여 들어가는 잡음이라 직접 볼 수 없다. 우리가 실제로 계산할 수 있는 건 잔차(실제값 − 예측값)이고, 잔차에는 순수한 오차와 모델이 잘못 맞춘 부분(모형화 오차)이 같이 들어 있다. 모델은 세상의 모든 요인을 넣을 수 없으니(완전성·복잡성) 오차는 항상 남고, 그 부분을 보면 어떤 변수를 더 넣어야 할지 힌트를 얻을 수 있다(통찰력). 오차는 서로 독립이고 평균 0, 분산이 일정한 정규분포를 따른다고 가정한다.

핵심 단어: 관찰 불가 vs 잔차는 계산 가능 · 잔차 = 순수 오차 + 모형화 오차 · iid N(0, σ²)

E5추론통계와 머신러닝의 차이를 설명하세요.서술

둘 다 표본 데이터를 쓰지만, 추론통계는 표본을 보고 모집단이 어떤지(관계가 있는지, 영향을 주는지)를 알아내는 게 목적이고, 머신러닝은 표본으로 학습해서 처음 보는 새 데이터를 정확히 예측하는 게 목적이다. 자동차 대여로 말하면, 추론통계는 "대여 시간이 가격에 영향을 준다"고 결론 내리고, 머신러닝은 "2시간 빌리면 20,000원"이라고 예측한다. 그래서 머신러닝은 학습/테스트 데이터를 나누고 과대적합을 조심한다.

핵심 단어: 모집단 이해 vs 새 데이터 예측 · 일반화 · 테스트 세트 · 과대적합

E6다중회귀분석은 왜 하나요?서술

현실의 결과는 한 가지 요인으로만 결정되지 않는다. 예금 유치액은 홍보비용뿐 아니라 직원 수, 지점 크기에도 영향을 받는다. 독립변수를 여러 개 넣으면 각 변수의 영향을 다른 변수를 고정한 상태에서 따로 볼 수 있고, 더 정확하게 설명·예측할 수 있다. 대신 변수가 많아지면 쓸모없는 변수, 서로 겹치는 변수(다중공선성)가 생기므로 변수 제거와 가정 검정이 필요하다.

핵심 단어: 여러 요인 · 더 정확한 설명/예측 · 변수별 영향 · 다중공선성 주의

개념 · 계산 퀴즈

Q1추론통계와 기계학습의 목표 차이를 한 문장씩 쓰시오.서술

추론통계: 표본으로 모집단의 특성을 이해·추론한다. 기계학습: 표본으로 학습해 새로운 데이터를 정확히 예측한다 (일반화).

Q2기계학습에서 과대적합이란?서술

모델이 노이즈·이상치까지 포함해 훈련 데이터를 너무 잘 학습해서 새 데이터에 대한 성능이 떨어지는 현상.

Q3y = β₀ + β₁x + ε 에서 각 기호의 이름과 의미는?서술

β₀ 상수(절편): x가 0일 때 y의 기준값. β₁ 회귀계수: x 1단위 증가 시 y의 평균 변화량. x 독립변수, y 종속변수, ε 오차항(관찰 불가능한 잡음, iid N(0, σ²) 가정).

Q4오차와 잔차의 차이는?서술

오차는 데이터 생성 시 섞이는 본질적 잡음으로 관찰할 수 없다. 잔차는 관찰값 − 예측값으로 계산할 수 있다. 잔차 = 순수 오차 + 모형화 오차.

Q5오차항의 특징 4가지를 쓰시오.암기

완전성, 복잡성, 유연성, 통찰력.

Q6회귀분석 프로세스 4단계는?암기

① 산점도 그리기 ② 회귀모형 선택 ③ 회귀계수 추정 ④ 모형 적용이 옳은지 판단.

Q7X = [1, 2, 3, 4, 5], Y = [2, 4, 5, 4, 5] 일 때 β̂₁, β̂₀ 를 구하시오.계산

X̄ = 3, Ȳ = 4. Σ(X−X̄)(Y−Ȳ) = (−2)(−2) + (−1)(0) + 0 + (1)(0) + (2)(1) = 6. Σ(X−X̄)² = 10.

β̂₁ = 6/10 = 0.6, β̂₀ = 4 − 0.6×3 = 2.2 → ŷ = 2.2 + 0.6x

Q8상박부 = −3.66 + 1.197 × 대퇴부 일 때 대퇴부 50 cm의 예측 상박부 길이는?계산

−3.66 + 59.85 = 56.19 ≈ 56.2 cm

Q9Cov(X, Y) = 0 이면 두 변수는 반드시 독립인가?O/X

X. 독립이면 Cov = 0이지만, 역은 성립하지 않는다. 공분산·상관계수는 직선적 관계만 잡기 때문에 곡선 관계가 있어도 0이 나올 수 있다.

Q10상관계수를 공분산 대신 쓰는 이유는?서술

공분산은 단위·스케일에 따라 크기가 달라져 비교가 어렵다. 두 변수의 표준편차로 나눠 정규화하면 −1 ~ 1 범위가 되어 관계의 강도와 방향을 비교할 수 있다.

Q11SST = 2000, SSE = 500, n = 50, k = 3 일 때 R²와 Adjusted R²는?계산

R² = 1 − 500/2000 = 0.75

Adj R² = 1 − (500/46) / (2000/49) = 1 − 10.870/40.816 = 0.734

Q12독립변수를 계속 추가하면 R²는 어떻게 되며, 그래서 무엇을 쓰는가?서술

R²는 의미 없는 변수를 넣어도 올라간다. 그래서 자유도(n − k − 1)를 반영한 Adjusted R²로 판단한다.

Q13실제값 [10, 12, 15], 예측값 [11, 12, 13] 일 때 MAE, MSE, RMSE는?계산

오차: −1, 0, 2. MAE = (1+0+2)/3 = 1.0. MSE = (1+0+4)/3 = 1.667. RMSE = √1.667 = 1.291.

Q14이상치에 민감한 지표 2개는? MAPE와 MPE의 차이는?암기

MSE, RMSE (제곱하기 때문). MAPE는 절대값이라 "얼마나 틀렸나", MPE는 부호를 유지해 "어느 쪽으로 틀렸나"(과대/과소)를 본다.

Q15Residual standard error: 1.489 on 998 degrees of freedom, 단순회귀일 때 표본 수 n은?계산

자유도 = n − k − 1 = 998, k = 1 → n = 1000.

Q16summary 출력에서 F-statistic의 p-value < 2.2e-16 의 의미는?해석

H₀ "독립변수는 종속변수를 유의미하게 설명하지 않는다"를 기각한다. 즉 회귀모형 전체가 통계적으로 유의하다.

Q17anova(result1, result)에서 result1 = lm(y ~ 1) 은 무엇이고 왜 비교하는가?서술

result1은 독립변수 없이 평균으로만 예측하는 모델. 두 모델의 잔차제곱합 차이를 검정해서, 변수를 넣은 모델이 평균만 쓰는 것보다 유의하게 나은지 확인한다 (p < 0.05면 의미 있음).

Q18다중회귀 가정 5가지와 각 R 검정 함수는?암기

선형성(Residuals vs Fitted 그래프), 등분산성 bptest, 독립성 durbinWatsonTest, 정규성 shapiro_test, 다중공선성 vif.

Q19shapiro_test 결과 p = 0.90 이다. 해석은?해석

p > 0.05 → H₀(잔차가 정규분포를 따른다) 채택 → 정규성 만족.

Q20bptest 결과 p = 0.003 이다. 해석은?해석

p < 0.05 → 등분산 가정 기각 → 이분산성. 잔차의 분산이 일정하지 않다.

Q21Durbin-Watson 통계량이 0.6 이면? 2.0 이면?해석

0.6: 0에 가까움 → 양의 자기상관 (독립성 위반). 2.0: 1.5~2.5 사이 → 잔차 독립.

Q22어떤 독립변수를 나머지 변수로 회귀했더니 R² = 0.9 였다. VIF와 판단은?계산

VIF = 1/(1 − 0.9) = 10 → 기준 10 이상이므로 다중공선성이 있다고 판단.

Q23다중공선성이 있으면 어떤 문제가 생기나?서술

회귀계수 값이 매우 커지고 변동성이 커져서, 추정된 계수의 부호가 실제와 반대로 나올 수 있다. 계수 해석을 믿을 수 없게 된다.

Q24max(cooks.distance(result2)) = 0.12 이다. 판단은?해석

0.5 미만 → 모형을 흔드는 영향점 없음.

Q25AIC의 공식과 판단 기준, 변수선택 3가지 방법은?암기

AIC = −2·log-likelihood + 2k. 절대 기준 없이 작을수록 좋은 모델. 후진소거법(backward), 전진선택법(forward), 단계적선택법(both).

Q26Shapiro-Wilk와 Kolmogorov-Smirnov 검정은 각각 언제 쓰나?암기

Shapiro-Wilk: 표본 2,000 미만. Kolmogorov-Smirnov: 2,000 초과.
